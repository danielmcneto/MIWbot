## M.I.W

**M.I.W** was made with the ideia of bring micro-controller specifications, quotes, and bot self-diagnostics directly inside your Slack workspace. Instead of needing to open multiple tabs to look needed information and details.

---

## Commands

 `/miw-wiki` | Queries the Wikipedia REST API to fetch summaries instantly in-chat. 
 
 `/miw-random` | Pulls a random quote to elevate you and your team moral. 
 
 `/miw-status` | Return info about the runtime environment. 
 

---

## Built with

* Python 3.14.3
* `slack_bolt` (Slack Socket Mode)
* REST / HTTP requests (`requests`, `aiohttp`)
* Render (24/7 Web Service)
* Git & GitHub
